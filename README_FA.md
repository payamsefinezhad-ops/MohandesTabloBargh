# مهندس تابلو برق — نمونه اولیه اندروید

این بسته یک **نمونه اولیه سورس اندروید** است، نه APK نهایی.

## امکانات موجود
- رابط کاربری فارسی با تم مشکی و سبز
- صفحه اصلی مفهومی
- فهرست نمونه تجهیزات و فیلتر دسته‌بندی
- جست‌وجوی نام قطعه در داده‌های نمونه

## باز کردن پروژه
1. Android Studio را نصب کنید.
2. پوشه `MohandesTabloBargh` را باز کنید.
3. اجازه دهید Gradle وابستگی‌ها را دریافت کند.
4. یک دستگاه اندروید یا شبیه‌ساز انتخاب کنید.
5. گزینه Run را بزنید.

## وضعیت و محدودیت‌ها
- هنوز APK ساخته یا روی دستگاه آزمایش نشده است.
- داده‌های قطعات فعلاً نمونه‌اند؛ هیچ شماره فنی، دیتاشیت یا تصویر سازنده‌ای جعل نشده است.
- اتصال هوش مصنوعی، پایگاه داده Room، نقشه‌کش گرافیکی، خروجی PDF و موتور اعتبارسنجی هنوز پیاده‌سازی نشده‌اند.
- برنامه در این مرحله **راهنمای اجرایی سیم‌کشی برق‌دار** تولید نمی‌کند. هر نقشه آینده باید با دیتاشیت همان مدل، شرایط نصب، حفاظت‌ها و استانداردهای مربوط بررسی و توسط فرد واجد صلاحیت تأیید شود.

## شناسه برنامه
`ir.example.mohandestablo`

## ساخت APK بدون کامپیوتر (با گوشی و GitHub Actions)

1. در مرورگر گوشی وارد github.com شوید و یک حساب بسازید یا وارد حساب خود شوید.
2. یک مخزن (Repository) جدید و ترجیحاً Private بسازید.
3. فایل ZIP را از حالت فشرده خارج کنید؛ پوشه داخلی `MohandesTabloBargh` را در مخزن بارگذاری کنید، به‌طوری‌که فایل‌های `settings.gradle.kts` و پوشه `app` در ریشه مخزن باشند.
4. در مخزن، زبانه Actions را باز کنید و اجرای گردش‌کار `Build Android APK` را انتخاب کنید. اگر اجرای خودکار با بارگذاری فایل‌ها فعال نشد، از گزینه Run workflow استفاده کنید.
5. پس از پایان موفق، وارد اجرای انجام‌شده شوید و از بخش Artifacts فایل `MohandesTabloBargh-debug-apk` را دریافت کنید.
6. ZIP مربوط به Artifact را باز کنید و فایل `app-debug.apk` را روی گوشی نصب کنید.

این روش به کامپیوتر نیاز ندارد، اما به حساب GitHub و اینترنت نیاز دارد. اولین ساخت ممکن است خطای وابستگی یا پیکربندی نشان دهد؛ در آن صورت متن خطا را بفرستید تا پروژه اصلاح شود. APK خروجی، نسخه آزمایشی (debug) است و هنوز برای انتشار عمومی امضا نشده است.

برای ساخت APK بدون Android Studio از فایل `BUILD_APK_FA.md` و گردش‌کار `.github/workflows/build-apk.yml` استفاده کنید.
